One source. Every agent.

agentweave turns skills, rules, and instructions into a clean, drift-aware sync flow for the agent runtimes your team actually uses.

GitHub repo Get started
agentweave sync 
$ agentweave add github:NestDevLab/core-agent-pack
$ agentweave sync --adapter openclaw --dry-run
$ agentweave sync --adapter openclaw
# managed files stay managed; local overlays stay yours

Designed for agent stacks that keep moving.

A

Pluggable adapters

Point a runtime at its paths with JSONC config, or use bundled adapters for common agent tools.

S

Stays in sync

Plan first, then apply. Hash manifests keep generated runtime files honest across updates.

T

Your tweaks survive

Local overlays and additive rules let teams customize without forking upstream packages.

R

Custom runtimes

Private runtime? Drop in a local adapter config and keep it inside your own workspace.

How it works

Author package Skills, rules, instructions, and future artifacts live upstream.
→
Workspace control plane .agentweave stores locks, overlays, overrides, and local intent.
→
Runtime output Sync writes generated files into OpenClaw, Claude, Codex, or private runtimes.
